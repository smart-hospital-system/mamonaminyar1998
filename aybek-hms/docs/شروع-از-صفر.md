# شروع از صفر — شفاخانهٔ ایبک
### قدم‌به‌قدم: کجا بروم، چه را بزنم، چه چیزی باید ببینم

این راهنما برای کسی نوشته شده که **هیچ چیز** از کامپیوتر نمی‌داند.
هر قدم سه بخش دارد: **کجا برو** · **چه بزن** · **چه ببین**.
اگر «چه ببین» را ندیدی، جلو نرو؛ برو به بخش «اگر گیر کردی» در پایان.

---

# بخش اول — نصب (یک بار، حدود ۱۰ دقیقه)

## قدم ۰: کدام حالت را دارید؟

| اگر این را دارید | این کار را بکن |
|---|---|
| **CD یا DVD** | دیسک را در کمپیوتر بگذار |
| **فلش USB** | فلش را وصل کن و پوشهٔ `Aybek-DISC-v7` را باز کن |
| **فایل زیپ** | روی فایل `.zip` راست‌کلیک کن → **Extract All** → یک پوشه ساخته می‌شود |

## قدم ۱: فایل `START-HERE.bat` را پیدا کن و دوبار کلیک کن

- **کجا برو:** داخل همان دیسک/فلش/پوشه
- **چه بزن:** روی `START-HERE.bat` **دوبار کلیک** (نه یک بار)
- **چه ببین:** یک پنجرهٔ سیاه باز می‌شود و می‌نویسد `[1/5] Copying…`

> اگر ویندوز پیام آبی **«Windows protected your PC»** داد:
> **More info** → **Run anyway**.
> این پیام برای همهٔ برنامه‌های نصب‌شده از دیسک ظاهر می‌شود، خطر نیست.

## قدم ۲: دستت را از موس بردار و صبر کن

- **چه ببین:** پنجرهٔ سیاه خط‌به‌خط جلو می‌رود: `[1/5]` … `[5/5]`
- **چقدر:** ۵ تا ۱۰ دقیقه. **پنجره را نبند.**
- آخر کار، خودِ مرورگر باز می‌شود و صفحهٔ ورود شفاخانه می‌آید.

> اگر پنجرهٔ سیاه گفت «Node.js was not found»: یعنی برنامهٔ پایه نصب نیست.
> فایل `TOOLS\node-v20-x64.msi` را نصب کن، بعد دوباره `START-HERE.bat` را بزن.

## قدم ۳: وارد شو

- **چه ببین:** صفحهٔ `http://localhost:3000/hms/login`
- **چه بزن:**
  - ایمیل: `doctor@aybek.hospital`
  - رمز: `mamonaminyar`
  - دکمهٔ **Sign in / ورود**
- **چه ببین:** صفحهٔ اصلی شفاخانه با کارت‌های رنگی.

✅ **تا اینجا نصب تمام است.** از حالا هر روز فقط: آیکن **Aybek HMS** روی دسکتاپ → دوبار کلیک.

# بخش دوم — هشت قدم داخل برنامه (یک بار، حدود ۳۰ دقیقه)

> این هشت قدم در خود برنامه هم هست: منوی کنار → **«از اینجا شروع کنید»** (`/hms/start`).
> آنجا هر قدم یک دکمهٔ **«مرا ببر»** دارد که مستقیم به همان صفحه می‌برد.

## قدم ۱ — رمز را عوض کن (۱ دقیقه) ⚠️ مهم‌ترین قدم
| | |
|---|---|
| **کجا برو** | منوی کنار → **کارمندان** (`/hms/team`) |
| **چه بزن** | نام خودت را پیدا کن → آیکن **کلید** 🔑 → دکمهٔ **«تولید»** → **«تعیین رمز»** |
| **چه ببین** | یک **کارت دسترسی** با رمزی مثل `GANU-FER4-WURE-KUH4` |

**کارت را چاپ کن و در کشو بگذار.** رمز را روی صفحه یا در واتس‌اپ نگه ندار.

## قدم ۲ — نام شفاخانه را بنویس (۴ دقیقه)
| | |
|---|---|
| **کجا برو** | **تنظیمات** → بخش **هویت** (`/hms/settings?section=identity`) |
| **چه بزن** | نام شفاخانه، تلفن، شمارهٔ اضطراری، آدرس، شهر را پر کن → پایین صفحه **ذخیره** |
| **چه ببین** | پیام سبز «ذخیره شد» |

بعد: **تنظیمات → ظاهر و چاپ** → یک تم انتخاب کن (مثلاً Obsidian Gold) و یک کاغذ نسخه.

## قدم ۳ — برای هر کارمند یک حساب بساز (۸ دقیقه)
| | |
|---|---|
| **کجا برو** | **کارمندان** → دکمهٔ **«افزودن کارمند»** |
| **چه بزن** | نام + ایمیل + نقش (نرس / دواساز / داکتر / استقبال) → کنار رمز **«تولید»** → **ایجاد حساب** |
| **چه ببین** | کارت دسترسی همان شخص — چاپ کن و یک بار به او بده |

> **هرگز یک حساب مشترک نساز.** حساب مشترک یعنی هیچ‌کس نمی‌فهمد چه کسی نسخه را امضا کرده.

## قدم ۴ — یک بیمار آزمایشی (۵ دقیقه)
| | |
|---|---|
| **کجا برو** | **بیماران** → **«بیمار جدید»** |
| **چه بزن** | نام، جنس، تلفن → ذخیره |
| **بعد** | پرونده را باز کن → **«معاینهٔ جدید»** → شکایت و تشخیص → **ذخیره** |
| **بعد** | در همان صفحه، زیر **نسخه** یک دوا اضافه کن → **«امضا»** |
| **بعد** | **دواخانه** → همان نسخه → **«تحویل»** (موجودی خودش کم می‌شود) |
| **بعد** | **بل‌ها** → **ساخت بل** → **دریافت پول** |

این یک چرخهٔ کامل است: بیمار → معاینه → نسخه → دوا → پول. تمام سیستم همین است، بقیه‌اش تکرار.

## قدم ۵ — لابراتوار، اکسری، وارڈ (۶ دقیقه)
| بخش | چه بزن |
|---|---|
| **لابراتوار** | سفارش را باز کن → **نمونه‌گیری** → نتیجه را بنویس → **نتیجه** → **تأیید** |
| **اکسری** | **قبول** → گزارش را بنویس → **گزارش** |
| **بستری** | یک بستر آزاد → **بستری** · وقتی رفت: **رخصتی** → **پاک‌سازی** |
| **عملیات** | **ثبت** → **شروع** → **تکمیل** |

## قدم ۶ — یک نسخه چاپ کن (۳ دقیقه)
| | |
|---|---|
| **کجا برو** | **نسخه‌ها** → یک نسخهٔ امضاشده را باز کن |
| **چه بزن** | **چاپ** → در پنجرهٔ چاپ: کاغذ **A4**، حاشیه **Default** |
| **چه ببین** | سربرگ شفاخانه، نام داکتر، کادر حساسیت |

اگر زبان را **دری** کنی، همین برگه راست‌به‌چپ چاپ می‌شود.

## قدم ۷ — پشتیبان (۲ دقیقه)
| | |
|---|---|
| **کجا برو** | **تنظیمات → داده و پشتیبان** |
| **چه بزن** | **«دانلود پشتیبان»** → فایل را روی فلش ذخیره کن |
| **بعد** | کلمهٔ `RESET` را بنویس → **«بازسازی دادهٔ نمونه»** (برای تمرین؛ برگشت‌ناپذیر) |

## قدم ۸ — دو میان‌بر که وقت نجات می‌دهد (۲ دقیقه)
| | |
|---|---|
| **Ctrl + K** | هر جا بزنی: جستجوی بیمار، نسخه، بل، دوا، کارمند |
| **«از ایبک بپرسید»** (`/hms/ask`) | بنویس: «امروز چقدر عاید شد؟» · «چه دوا کم است؟» · «چه کسی پرداخت نکرده؟» |

✅ **تمام. از فردا صبح شفاخانه با دادهٔ واقعی کار می‌کند.**

# بخش سوم — کدهای قوی (رمزها)

**قاعدهٔ طلایی:** رمز کوتاه = در باز.

| رمز | نتیجه |
|---|---|
| `hospital123` | ❌ رد می‌شود |
| `mamonaminyar` | ⚠️ فقط برای اولین ورود؛ فوراً عوض کن |
| `Kabul-surgery-2026-ward` | ✅ قوی (جملهٔ طولانی) |
| `GANU-FER4-WURE-KUH4` | ✅ عالی (تولید خود برنامه) |

- دکمهٔ **«تولید»** در هر جای برنامه یک رمز ۱۶ حرفی می‌سازد که می‌شود آن را با صدا هم به همکار گفت (حروف سردرگم مثل `0/O` و `1/I` در آن نیست).
- برنامه رمز ضعیف را **قبول نمی‌کند** — این عیب نیست، محافظت است.
- **پنج بار رمز غلط** = همان حساب ۱ دقیقه قفل می‌شود؛ هر بار بیشتر، تا ۱۵ دقیقه. حساب‌های دیگر آزاد می‌مانند.
- هر ورود، امضا، تحویل دوا و تغییر در **«ثبت وقایع»** (`/hms/audit`) با نام شخص نوشته می‌شود و از داخل برنامه پاک نمی‌شود.

# بخش چهارم — اگر گیر کردی

| چه دیدی | چه کار کن |
|---|---|
| پنجرهٔ سیاه سریع بسته شد | `START-HERE.bat` را با راست‌کلیک → **Run as administrator** |
| `Port 3000 already in use` | پنجرهٔ قبلی سرور را ببند، یا: `powershell -File aybek-hms\scripts\install\04-start.ps1 -Port 3001` |
| صفحه باز نمی‌شود | آدرس را دستی بزن: `http://localhost:3000/hms/login` |
| «Trial expired» | **لایسنس و سریال‌ها** → سریال را وارد کن |
| «Too many failed attempts» | ۶۰ ثانیه صبر کن؛ عمداً این‌طور است |
| رمزم را فراموش کردم | با حساب مدیر (`doctor@…`) وارد شو → **کارمندان** → کلید 🔑 → رمز تازه |
| داده‌ها نیست | فایل `data\slotly.db` را از پشتیبان برگردان |
| هر چیز دیگر | در پنجرهٔ PowerShell بزن: `powershell -File aybek-hms\scripts\install\10-doctor.ps1` — خودش می‌گوید مشکل چیست |
