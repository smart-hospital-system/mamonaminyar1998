# تحویل نهایی — شفاخانه ده بستر جراحی ایبک

**نام رسمی سیستم:** Aybek Ten-Bed Specialy Surgical Hospital
**نام فارسی/دری:** شفاخانه ده بستر جراحی ایبک
**مالک:** داکتر مامون امینیار
**رمز ورود پیش‌فرض:** `mamonaminyar`
**نسخه:** v7 — «نسخهٔ دقیق» (همهٔ عیب‌های شناخته‌شده رفع، هوش کلینیکی، جستجوی سراسری و طراحی تازه)

این سند راهنمای دقیق تحویل است. اگر فقط یک صفحه بخوانید، همین صفحه باشد.
اگر تازه‌کار هستید و می‌خواهید بدانید **کجا بروید و چه را بزنید**، اول
`DOCS/شروع-از-صفر.md` را بخوانید — همان سند، با ترتیب دقیق کلیک‌ها.
راهنمای کامل‌تر در پکیج موجود است: `DOCS/GUIDE-FA.md` (کتاب جیبی فارسی، ۲۲ فصل)
و `DOCS/USER-GUIDE.md` (راهنمای انگلیسی برای کارمندان).

## ۲. نصب روی این کمپیوتر (ویندوز) — ۶ گام

**پیش‌نیاز:** ویندوز ۱۰ یا ۱۱ (۶۴ بیتی)، ۴ گیگابایت RAM، ۲ گیگابایت فضای آزاد، Node.js 20 یا بالاتر.

1. **کاپی کنید.** محتوای دیسک را در مسیر کوتاه و بدون فاصله کاپی کنید:
   `C:\AybekHMS` — از مسیرهای طولانی یا `Desktop` استفاده نکنید.
2. **Node.js را نصب کنید** (فقط یک بار): فایل نصبی را اگر در `TOOLS\` گذاشته‌اید همان را نصب کنید،
   وگرنه از `nodejs.org` نسخهٔ LTS (۲۰ یا بالاتر) را بگیرید. برای بررسی، در PowerShell بنویسید:
   `node -v` → باید `v20` یا بالاتر بدهد.
   (`TOOLS\PUT-NODEJS-INSTALLER-HERE.txt` می‌گوید فایل نصبی را کجا بگذارید تا نصب آفلاین شود.)
3. **روی `START-HERE.bat` دوبار کلیک کنید.** همین یک کار کافی است: نسخه را در
   `C:\AybekHMS` کاپی می‌کند، Node را بررسی می‌کند، بسته‌ها را نصب می‌کند، دیتابیس نمونه را
   می‌آورد، برنامه را می‌سازد و مرورگر را باز می‌کند. حدود ۵ تا ۱۰ دقیقه.
   (اگر ویندوز پیام «Windows protected your PC» داد: More info ← Run anyway.
   و اگر اسکریپت‌ها اجرا نشدند، در PowerShell همین یک خط را بزنید و START-HERE را دوباره اجرا کنید:
   `Set-ExecutionPolicy -Scope Process Bypass`)
4. **گام‌به‌گام (اگر خواستید دستی انجام دهید):** اول محتوای پوشهٔ `APP` را در `C:\AybekHMS` کاپی کنید،
   بعد در PowerShell:
   ```powershell
   cd C:\AybekHMS
   Set-ExecutionPolicy -Scope Process Bypass
   .\aybek-hms\scripts\install\01-setup.ps1     # بررسی ویندوز و Node
   .\aybek-hms\scripts\install\02-install.ps1    # نصب بسته‌ها
   .\aybek-hms\scripts\install\03-seed.ps1       # ساخت دادهٔ نمونه
   .\aybek-hms\scripts\install\05-build.ps1      # build برای سرعت بیشتر
   .\aybek-hms\scripts\install\06-shortcut.ps1   # آیکن روی دسکتاپ
   .\aybek-hms\scripts\install\04-start.ps1      # شروع سرور + باز کردن مرورگر
   ```
5. **شروع بعدی:** آیکن **Aybek HMS** روی دسکتاپ، یا:
   ```powershell
   cd C:\AybekHMS ; .\aybek-hms\scripts\install\04-start.ps1
   ```
   آدرس در مرورگر باز می‌شود: `http://localhost:3000/hms/login`
6. **ورود:** ایمیل `doctor@aybek.hospital` و رمز `mamonaminyar`.
   سپس **فوراً** در `Settings → Staff` رمز را عوض کنید و یک کاربر برای هر کارمند بسازید.

> **نکته امنیتی:** رمز `mamonaminyar` رمز تحویل است، نه رمز کاری. پیش از اینکه بیمار واقعی ثبت شود آن را عوض کنید.

## ۳. نصب روی کمپیوتر دوم (بدون انترنت) — ۵ گام

1. زیپ `COPY-TO-ANOTHER-PC\Aybek-HMS-source-v6.zip` را روی فلش ببرید.
2. روی کمپیوتر دوم در `C:\AybekHMS` از حالت فشرده خارج کنید.
3. Node.js 20 LTS را از همان فلش (فولدر `TOOLS`) نصب کنید — فایل نصب را اگر خودتان دانلود
   نکرده‌اید، یک بار روی کمپیوتر وصل از `nodejs.org` بگیرید و در `TOOLS` بگذارید.
4. نصب بدون انترنت: **کل پوشهٔ `node_modules`** را از کمپیوتر اول (مسیر `C:\AybekHMS\node_modules`)
   با فلش به همان مسیر در کمپیوتر دوم کاپی کنید، بعد:
   ```powershell
   cd C:\AybekHMS
   Set-ExecutionPolicy -Scope Process Bypass
   .\aybek-hms\scripts\install\01-setup.ps1
   .\aybek-hms\scripts\install\05-build.ps1
   .\aybek-hms\scripts\install\04-start.ps1
   ```
   اگر `node_modules` همراه نبود، روی کمپیوتر دوم با انترنت: `.\aybek-hms\scripts\install\02-install.ps1`
   (این تنها گامی است که به انترنت نیاز دارد؛ همهٔ گام‌های دیگر آفلاین‌اند).
5. **داده‌های شفاخانه را منتقل کنید** (اگر می‌خواهید همان بیماران باشد):
   فایل `data\slotly.db` (و اگر بودند `slotly.db-wal` و `slotly.db-shm`) را از کمپیوتر اول
   روی فلش کاپی کنید و در `C:\AybekHMS\data\` کمپیوتر دوم جای آن بگذارید — **در حالتی که هر دو برنامه بسته باشند**.
   بعد برنامه را باز کنید. همهٔ بیماران، نسخه‌ها، موجودی و بل‌ها همان‌جا هستند.

## ۵. پشتیبان — سه راه، همه آزمون‌شده

1. **از داخل برنامه:** `Settings → Data & backup` ← «Download backup»
   فایل `aybek-backup-YYYY-MM-DD-HHmm.json` — همهٔ ۱۹ جدول + تنظیمات + لایسنس.
2. **فایل کامل:** `data\slotly.db` را در حالت بسته بودن برنامه کاپی کنید (کامل‌ترین راه).
3. **خودکار هر شب:**
   ```powershell
   cd C:\AybekHMS
   .\aybek-hms\scripts\install\07-backup.ps1 -Schedule -At 20:00
   ```
   بازگردانی: `.\aybek-hms\scripts\install\08-restore.ps1`

**عادت پیشنهادی:** هفته‌ای یک بار پشتیبان روی فلش + یک کاپی در جای دوم (نه روی همان کمپیوتر).

### بازگرداندن شفاخانهٔ نمونه (برای تمرین/نمایش)
`Settings → Data & backup` ← کادر را پر کنید با کلمهٔ `RESET` ← «Rebuild demo data».
همه چیز پاک و شفاخانهٔ نمونه بازسازی می‌شود — **برگشت‌ناپذیر**، پس اول پشتیبان بگیرید.
از خط فرمان هم: `npm run hms:reset`

## ۹. چه چیزی در این نسخه درست شد (خلاصهٔ فنی)

- تنظیمات حالا **اعتبارسنجی** می‌شود: عدد نامعتبر قبول نمی‌شود، مقدار خارج از محدوده
  به حد مجاز **محدود** می‌شود، و کلید ناشناخته با خطای ۴۲۲ رد می‌شود.
- شناسهٔ ناشناخته در لابراتوار/اکسری/عملیات/بستر حالا **۴۰۴** می‌دهد، نه «موفق».
- تحویل دو بار دوا، نسخهٔ قبلاً تحویل‌شده یا باطل‌شده: **۴۰۹** با توضیح.
- هر عملیاتی که سرور رد کند، حالا روی صفحه **خطای واقعی** نشان می‌دهد (قبلاً «موفق» نشان می‌داد).
- صفحهٔ **۴۰۴** و صفحهٔ **خطا** داخل شفاخانه، دو زبانه، با کد پیگیری.
- پیوند مستقیم از پروندهٔ بیمار به اتاق معاینه (`?patient=`) کار می‌کند.
- وقتی دسترسی رد شود، **بنر توضیح** نشان داده می‌شود، نه پرت شدن بی‌دلیل.
- صفحهٔ **Data & backup** که در راهنما وعده داده شده بود، واقعاً ساخته شد.
- `npm run hms:reset` برای بازگرداندن دادهٔ نمونه بدون دست زدن به دادهٔ دیگر.

**آزمون نهایی:** `tsc` بدون خطا، `next build` بدون خطا، ۱۷ صفحه × ۲ زبان = ۲۰۰ و RTL درست،
۱۲ API = ۲۰۰، همهٔ جریان‌های کاری (پذیرش ← معاینه ← نسخه ← تحویل، لابراتوار، اکسری،
بستر، عملیات، بل، موجودی) از اول تا آخر اجرا و تأیید شد، و `npm run hms:verify` هر ۱۹ جدول را سالم گزارش می‌کند.

## ۱۱. تازه در نسخهٔ ۷ — چهار ابزار که کار روزانه را کوتاه می‌کند

### الف) «از ایبک بپرسید» — `/hms/ask`
سوال را مثل حرف زدن بنویسید (انگلیسی یا دری): «امروز چقدر عاید شد؟» · «چه دوا کم است؟»
· «چه کسی پرداخت نکرده؟» · «بسترها چقدر پر است؟»
جواب: یک عدد بزرگ، یک پاراگراف توضیح، یک جدول سند، و دکمه‌ای که شما را به صفحهٔ اقدام می‌برد.
هر صبح با پرسیدن «خلاصه» شروع کنید. بدون انترنت، بدون ارسال داده، جواب همیشه یکسان.

### ب) جعبه‌ابزار کلینیکی — `/hms/intelligence`
1. **NEWS2** هشدار زودهنگام: علایم حیاتی ← امتیاز، سطح خطر، دستور ارتقا.
2. **qSOFA** اسکرین سپسیس از همان اعداد.
3. **بررسی تداخل دوا** (۲۴ قاعده) با شدت، مکانیزم، اقدام و جایگزین.
4. **دوز اطفال بر اساس وزن** و **تنظیم دوز کلیوی (CrCl)**.
5. **تفسیر لابراتوار** با ۱۵ محدودهٔ مرجع و علامت بحرانی + **محاسبات بدن** (BMI، BSA، IBW، کاکرافت-گالت).

### ج) جستجوی سراسری با `⌘K`
بیمار، نسخه، بل، دوا، سفارش لابراتوار/اکسری، کارمند — از یک کادر. `↑` `↓` و `Enter`.
هشت جای آخر ذخیره می‌شود.

### د) خط زمانی بیمار + ثبت وقایع
پروندهٔ هر بیمار با **یک خط زمانی واحد** باز می‌شود (معاینه، نسخه، لابراتوار، اکسری،
بستری، عملیات، بل) با فلتر. و `/hms/audit` (مالک/داکتر ارشد) همهٔ تغییرات را با نام
شخص و زمان نشان می‌دهد، فلتر و **خروجی CSV** دارد و از داخل برنامه قابل ویرایش نیست.

### ه) طراحی و ظاهر
