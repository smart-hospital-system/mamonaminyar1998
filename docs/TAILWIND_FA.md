# تکمیل Tailwind — نسخهٔ ۰.۴.۱

این نسخه، ارتقای رابط روی نسخهٔ ۰.۴ شفاخانهٔ ایبک است. **Tailwind CSS و CLI نسخهٔ دقیق 4.3.3** در package.json و package-lock.json ثبت شده‌اند.

## چه چیزی منتقل شده است؟

- داشبورد اصلی: خوش‌آمدگویی، چهار کارت آمار، نمودار هفت‌روزه با جدول قابل‌خواندن، کارهای شخصی، دسترسی‌های بخش‌ها و ورود به استودیوی نسخه.
- کارت‌های پنج بخش و راهنمای سه‌مرحله‌ای: چیدمان responsive، حالت انتخاب، نشان مرحله و کنترل‌های قابل‌استفاده با کیبورد.
- راست‌به‌چپ، ده پالت ذخیره‌شده از جمله تم تاریک، دادهٔ واقعی API، نقش‌های دسترسی و فرمان‌های موجود حفظ شده‌اند.
- این یک مهاجرت مرحله‌ای است: فرم‌های طبی، sidebar/topbar، استودیو و استایل چاپ همچنان CSS اختصاصی قبلی دارند. **کل برنامه، React یا Next.js نشده و همهٔ CSSهای قبلی حذف نشده‌اند.**

## استفادهٔ عادی و آفلاین

برای اجرای شفاخانه **Node.js، npm و اینترنت لازم نیست**. فایل ساخته‌شدهٔ `frontend/tailwind.css` در ZIP همراه برنامه است و از `/assets/tailwind.css` محلی بارگذاری می‌شود؛ CDN، فونت اینترنتی یا Tailwind داخل مرورگر وجود ندارد.

روش نصب همان `docs/UPGRADE_V04_FA.html` است: ZIP را کامل استخراج، Python سازگار را جداگانه آماده و `Setup.cmd` را اجرا کنید. اگر نصب قبلی دارید، **روی پوشه یا دیتابیس قبلی نصب نکنید**؛ بکاپ بگیرید و ارتقای کنترل‌شده به پوشهٔ تازه را طبق راهنمای قبلی انجام دهید. برای این تغییر، schema یا دادهٔ مریضان تغییر نکرده است؛ همچنان schema 2 است.

Tailwind v4 به مرورگر جدید احتیاج دارد: حداقل Chrome/Edge 111، Safari 16.4 یا Firefox 128 مطابق الزامات پایهٔ v4. آزمون این نسخه با Chromium 141 انجام شده، نه همهٔ مرورگرها یا نسخه‌های قدیمی Windows. از مرورگر جدید و پشتیبانی‌شده استفاده کنید.

## مسیر فایل‌ها

| فایل | وظیفه |
|---|---|
| `frontend/dashboard.js` | ساخت HTML داشبورد اصلی با utilityهای واقعی Tailwind |
| `frontend/professional.js` | کارت‌ها و راهنمای پنج بخش؛ باقی امکانات قبلی حفظ شده |
| `frontend/tailwind.input.css` | ورودی، theme و منابع استخراج کلاس |
| `frontend/tailwind.css` | CSS ساخته‌شده و قابل‌توزیع، همراه ZIP |
| `scripts/check_tailwind.cjs` | بازسازی موقت و تطبیق خروجی با CSS همراه؛ خطا در صورت stale بودن |

کلاس‌ها پیشوند `tw:` دارند تا با کلاس‌های قبلی تداخل نکنند. **Preflight عمداً وارد نشده** تا reset سراسری روی فرم‌ها، جدول‌ها و اسناد چاپ A4 اثر نگذارد. متغیرهای رنگ موجود مثل `--panel` و `--teal` حفظ شده‌اند؛ تغییر پالت به چاپ نسخه سرایت نمی‌کند. کلاس‌های پویا باید به‌صورت رشته‌های کامل در منابع تعریف شوند، نه با چسباندن نام رنگ نامعلوم به پیشوند کلاس.

## فقط برای توسعه‌دهنده: ساخت دوبارهٔ CSS

این دستورها برای **توسعه** هستند، نه نصب عادی شفاخانه. Node.js سازگار با ابزار ساخت (ترجیحاً نسخهٔ LTS نگهداری‌شدهٔ ۲۲ یا جدیدتر) لازم است. نخست وابستگی‌ها از registry نصب می‌شوند؛ بعد از آماده‌بودن آن‌ها، خود build به CDN احتیاج ندارد.

از ریشهٔ سورس، هر بار یک دستور:

```powershell
npm ci --ignore-scripts
```

```powershell
npm run build:css
```

```powershell
npm run check:css
```

```powershell
npm run check
```

```powershell
npm test
```

برای کار پیوسته فقط در محیط توسعه:

```powershell
npm run watch:css
```

در پایان Ctrl+C. فایل خروجی `frontend/tailwind.css` را همراه سورس تغییرکرده توزیع کنید. خروجی در Git نادیده گرفته نشده و packager آن را داخل manifest قرار می‌دهد؛ sourceهای JS و CSS هم در بسته هستند. Windowsِ مشتری نیازی به کامپایل Rust یا نصب CLI ندارد.

## بررسی انجام‌شده

- **۸۲ آزمون پایتون و ۲۶ آزمون رابط** موفق شدند؛ کنترل syntax و تطبیق CSS با build نیز موفق بود.
- در Chromium، چیدمان محاسبه‌شدهٔ آمار در desktop چهار ستون و در عرض ۳۹۰ پیکسل یک ستون بود؛ border-radius و رنگ واقعی تم تاریک بررسی شدند، نه فقط وجود نام کلاس.
- تکمیل کار از خود داشبورد، راهنمای پنج بخش، موبایل بدون overflow و نبود هرگونه درخواست خارجی/CDN بررسی شد.
- مسیرهای واقعی ثبت مریض، یادداشت، نوبت، پیش‌نویس/ویرایش/انتخاب طرح ذخیره‌شده/تأیید و چاپ دوباره آزمایش شدند.
- **۲۰۰ PDF کوتاه هرکدام یک A4**؛ سند بلند شش صفحه و آخرین قلم محفوظ. این گواهی همهٔ چاپگرها یا همهٔ مقدارهای محتوا نیست.
- نصب بومی Windows/PowerShell و چاپگر فیزیکی در این محیط آزمایش نشده است. اعتبارسنجی بالینی/امنیتی همچنان لازم است.

آزمون افزودهٔ مرورگر: `tests/e2e/tailwind-smoke.cjs`؛ فقط روی محیط آموزشی با دادهٔ ساختگی اجرا شود. ابزار مرورگر، screenshotها، رمز پیش‌نمایش و DB داخل ZIP جمع‌آوری نمی‌شوند.
